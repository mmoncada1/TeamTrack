# TeamTrack presenter notes (target: 6–7 minutes)

1. **Title — 30 seconds.** “TeamTrack is a sideline app that follows a team from setup through the final whistle.”
2. **Problem — 45 seconds.** Describe the friction of switching between roster sheets, lineup notes, a timer, and a match log.
3. **Product — 60 seconds.** Focus on the soccer workflow. Mention flag football features briefly if time permits.
4. **Why try it — 45 seconds.** Emphasize a live view of field, bench, and minutes. AI suggestions require coach approval; do not imply they automatically change the match.
5. **Live demo — 3–4 minutes.** Use a prepared account and team with a roster and saved lineup. Start a match, substitute, log a goal, and show summary. If time is tight, skip creating the team and roster live. The AI assistant and voice commands require the deployed Vercel Functions and server-side Gemini key; omit them in a local `jac run --dev` demo.
6. **Try it — 30 seconds.** Show the GitHub link and local startup steps. The repository contains the README with full setup details. Replace this slide with a verified hosted URL or QR code if one is available before presenting.

The repository currently documents local startup, but no public deployment URL was found. Creating an account may depend on the Supabase project's authentication configuration.
