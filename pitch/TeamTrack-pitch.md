# TeamTrack

### Your team, lineup, and match day in one place

**A practical sideline tool for soccer coaches**

---

# The problem

- Rosters, lineups, substitutions, and match notes often live in different places.
- During a game, coaches need quick answers: Who is on the field? Who needs minutes? What happened?
- Reconstructing the match afterward takes extra work.

---

# What TeamTrack does

- **Prepare:** Create a team, add players, and save lineups.
- **Coach live:** Run the match clock, move players, substitute, record goals and cards, and see playing-time alerts.
- **Review:** Open match history and a post-match summary.
- **Plan:** Use a tactics whiteboard. Flag football teams also get formations, a playbook, and drive plans.

---

# Why try it?

### One workflow from setup to final whistle

- See the field, bench, and player time together.
- Get substitution suggestions from an AI assistant, then review each change before applying it.
- Keep team data tied to your account with cloud sync.

---

# Live demo: coach a match

1. Create or open a soccer team; show the roster and a saved lineup.
2. Create a match and start the clock.
3. Substitute a player; show the field and playing-time display updating.
4. Record a goal, then open the match summary.

**If the hosted AI function is available:** Ask for “3 best subs” and show the review flow.

# Try TeamTrack

### Source and setup

**[github.com/mmoncada1/TeamTrack](https://github.com/mmoncada1/TeamTrack)**

Install Jac 0.37.23, then run `jac install` and `jac run --dev` from the project folder. Open **http://localhost:8000**, create an account, and create a team.

**Start with:** one team → a few players → a lineup → a match.
